# 💙 Healify – Your Smart Health Record Companion

Healify is a **Flutter-based mobile app** that empowers users to store, manage, and securely share their medical records. With blockchain-backed data integrity, AI-driven health insights, and a scalable cloud-native backend, Healify is designed to transform the way individuals manage their health data.

---

## 🌟 Key Features

### 📁 Comprehensive Health Records  
Store and organize all types of medical documents in one place:
- Prescriptions  
- Lab reports  
- Diagnosis details  
- Treatment history  
- Images and videos  

### 🔐 Blockchain for Secure Sharing  
Built using **Solidity**, Healify ensures tamper-proof record sharing by leveraging blockchain.  
- Guarantees data authenticity and integrity  
- Share records with doctors, family, or friends securely  

### 🧠 AI-Powered Health Insights  
Integrated with **Gemini API** to:
- Analyze medical records  
- Generate **personalized health recommendations**  
- Predict potential risks and suggest **preventive measures**

### 🎨 Enhanced UI/UX  
- Stunning and **interactive Rive animations**  
- Clean, intuitive user interface for smooth navigation  

### 🚀 Scalable Cloud Architecture  
- Backend developed in **GoLang** and fully **Dockerized**  
- Deployed on **AWS EKS** for performance, scalability, and reliability  

### ☁️ Cloud Storage with AWS S3  
- All media and documents stored in **AWS S3**  
- Ensures high durability and **global accessibility**

### ⚡ Optimized Data Management  
- Uses **Prisma ORM** with **MongoDB** for efficient data handling  
- Fast queries and smooth performance even with large datasets
